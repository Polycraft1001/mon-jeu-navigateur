# mon-jeu-navigateur

Un jeu de course de voiture en 3D, jouable directement dans le navigateur (fait avec [Three.js](https://threejs.org/)).

▶️ **Jouer :** https://polycraft1001.github.io/mon-jeu-navigateur/

## Règles
Fais **3 tours** du circuit le plus vite possible. Ton meilleur temps est sauvegardé dans le navigateur.

## Contrôles
| Action | Clavier | Mobile |
|---|---|---|
| Accélérer | ↑ ou Z | ▲ |
| Freiner / reculer | ↓ ou S | ▼ |
| Tourner | ← → ou Q D | ◀ ▶ |
| Frein à main | Espace | ⛔ |
| Recommencer | R | bouton Rejouer |

## Fichiers
- `index.html` : la page et l'interface
- `style.css` : l'apparence
- `game.js` : le jeu (circuit, voiture, physique, chronomètre)
